content-box vs border-box

← Exact 300px Reference Bar →
1. box-sizing: content-box (Default)
Declared width: 300px + padding: 30px (x2) + border: 10px (x2)
Actual Total Width = 380px! (Overflows the 300px bar!)
2. box-sizing: border-box (Recommended)
Declared width: 300px includes the 30px padding and 10px border.
Actual Total Width = Exactly 300px!
