CSS Selectors Presentation

1. Element Selector (blockquote)

Explanation: Targets all elements of a specific type across the page.

blockquote {
  border-left: 5px solid blue;
  background-color: #e6f2ff;
}
Result:
This is a blockquote. It gets styled just by using its tag name!
Here is another one. It gets the exact same style automatically.

2. Class Selector (.card)

Explanation: Targets elements sharing a specific class name. Ideal for reusable components.

.card {
  padding: 20px;
  background-color: #ffe6e6;
  border: 1px solid red;
}
Result:
This div has class="card".

This is another class="card". You can reuse classes!

3. ID Selector (#main-highlight)

Explanation: Targets one specific element with a unique ID on the page.

#main-highlight {
  background-color: lightgreen;
  font-weight: bold;
}
Result:
This div has id="main-highlight". IDs should only be used once per page!

4 & 5. Descendant (space) vs Child (>)

Explanation:
- Descendant (.parent-box span) targets nested elements anywhere inside. (Colored Dark Blue)
- Child (.parent-box > span) targets only direct children. (Underlined and Red)

.parent-box span { color: darkblue; }
.parent-box > span { text-decoration: underline; color: red; }
Result:
I am a DIRECT child span (Underlined & Red).
I am a nested DESCENDANT span inside another div (Dark Blue only).

Explanation: Targets elements based on a specific attribute value.
