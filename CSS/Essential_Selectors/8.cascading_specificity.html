How the Cascade & Specificity Works in CSS

1. Normal Paragraph: Both p { color: blue; } and p { color: purple; } target me. Purple wins because it comes later in the CSS file (Source Order)!

2. Class Paragraph: Both p and .highlight target me. Orange wins because a Class selector has higher specificity than an Element selector!

3. ID Paragraph: p, .highlight, and #special all target me. Green wins because an ID selector beats both Class and Element selectors!

4. Inline Style Paragraph: Red wins because an inline style="" attribute beats ID, Class, and Element selectors!
